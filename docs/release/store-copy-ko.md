# 앱 소개·스토어 문구 초안

대상: PBI-099

## 짧은 소개

카메라 영상을 저장하지 않고 기기 안에서 관절 움직임을 분석하는 프라이버시 중심 운동 자세 코치입니다.

## 상세 소개

AI Healthcare Coach는 스쿼트 중 무릎 정렬, 자세 깊이와 좌우 균형을 실시간으로 안내합니다. 운동이 끝나면 저장된 관절 좌표와 규칙 이벤트로 리포트와 3D 리플레이를 만듭니다. 리플레이는 원본 영상이 아니며, 좌표 로그 저장 여부와 보관 기간은 사용자가 선택하고 언제든 삭제할 수 있습니다.

이 앱은 일반적인 피트니스 코칭을 위한 제품입니다. 질환을 진단하거나 치료·처방·재활 지시를 제공하지 않습니다. 통증, 흉통, 어지럼증 또는 심한 불편감이 있으면 운동을 중단하고 필요한 경우 의료 전문가의 도움을 받으세요.

## 개인정보 핵심 문구

- 원본 카메라 영상 저장·업로드 없음
- 운동 분석은 기본적으로 온디바이스 처리
- 좌표/요약 로그는 선택 저장, 세션별·전체 삭제 가능
- 콘텐츠 업데이트 통신과 운동 데이터는 분리

최종 배포 전 스토어 정책·법률 검토와 실제 지원 기능 대조가 필요하다.
