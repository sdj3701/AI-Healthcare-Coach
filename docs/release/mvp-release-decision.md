# MVP 출시 판정 리포트

대상: PBI-098

현재 판정: **보류 — 실기기·전문가·사용성 증거 대기**

## 자동 확인

- C++ 학습 모듈 빌드/테스트
- Unity 스크립트 컴파일
- 합성 좌표, 캘리브레이션, 오프라인 네트워크 가드, entitlement, MediaPipe 설치 결정론 QA
- 원본 영상 미저장 구조와 로컬 삭제 API

## 출시 필수 증거

- 지원 단말 매트릭스에서 10분 크래시 0, 평균 pose FPS 10 이상
- 전문가 규칙 검수 서명과 반영 버전
- Must 수동 시나리오 결과 및 결함 0건 또는 승인된 예외
- 개인정보/스토어 문구 법무 확인
- high risk 항목 담당자·완화책·승인일

## 즉시 보류 조건

- 원본 영상 또는 허용되지 않은 파일 생성
- 낮은 confidence 상태에서 자세 오류 판정 지속
- 진단·치료·재활 처방 표현 출력
- 안전 기능이 결제 상태에 따라 비활성화
- 지원 단말 반복 크래시, 지속 발열 경고, 삭제 실패

승인자, 승인 날짜, 앱/모델/규칙/프롬프트 버전을 실제 출시 회의에서 기록해야 한다.
