# MVP 출시 체크리스트

대상: PBI-104

- [ ] Unity 컴파일 및 결정론 QA 통과 증거 첨부
- [ ] C++ 학습 모듈 테스트 통과
- [ ] Must 기능 수동 시나리오 전체 실행
- [ ] 지원 단말 매트릭스와 10분 성능/배터리 결과
- [ ] 전문가 규칙 검수 서명·규칙 버전 반영
- [ ] high risk 대응 완료 또는 명시적 승인
- [ ] 원본 영상 파일 0건 검사
- [ ] 낮은 confidence 판정 중지 확인
- [ ] 세션별/전체 삭제 성공률 100%
- [ ] 비행기 모드 운동·리포트 fallback 완료
- [ ] 스토어·개인정보·안전 문구 법률/정책 검토
- [ ] 알려진 제한사항과 고객지원 FAQ 게시
- [ ] 앱/pose model/report model/rules/prompt/safety copy 버전 기록
- [ ] 출시 승인자와 승인 날짜 기록

하나라도 미확인인 Must 항목은 합격으로 추정하지 않는다. 체크리스트와 `mvp-release-decision.md` 판정이 불일치하면 출시를 보류한다.
