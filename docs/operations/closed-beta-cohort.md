# 클로즈드 베타 코호트 운영안

대상: PBI-103

규모: 20~50명, 2주. 모집 시 일반 피트니스 제품이며 의료 진단·치료가 아님을 고지한다.

## 과제

- 첫 실행 온보딩과 카메라 세팅
- 주 3회, 회당 스쿼트 8~12회
- 리포트와 좌표 기반 리플레이 확인
- 개인정보 신뢰도와 피드백 빈도 설문
- 마지막 날 전체 데이터 삭제 확인

## 최소 수집 KPI

운동 시작/완료, 캘리브레이션 성공, pose FPS 구간, 피드백 유형·횟수, 리포트/리플레이 조회, 삭제 성공, 1~5 설문만 수집한다. 원본 영상, 음성, 자유 텍스트 건강정보, 기기 광고 ID는 수집하지 않는다.

## 종료 리포트

코호트 수, 완료율, 카메라 세팅 중앙값, 크래시율, 저사양 비율, 피드백 불편 응답, 리포트 이해도, 개인정보 신뢰도, 삭제 성공률과 미해결 위험을 기록한다. 실제 참가 동의와 결과 없이는 이 항목을 완료로 표시하지 않는다.
