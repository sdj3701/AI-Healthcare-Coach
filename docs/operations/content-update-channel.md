# 모델·규칙·프롬프트 업데이트 채널

대상: PBI-102

운동 세션의 관절 좌표나 리포트를 업로드하지 않고, 버전 콘텐츠만 별도 채널에서 내려받는다. 다운로드는 운동 중이 아닐 때만 수행하고 다음 순서를 지킨다.

1. manifest의 앱 최소 버전, 패키지 버전, 파일 크기와 SHA-256을 확인한다.
2. staging 디렉터리에 저장한 뒤 모든 artifact를 검증한다.
3. `content_updates/versions/<version>`으로 원자적으로 승격하고 `current.txt`를 갱신한다.
4. 이전 버전을 `previous.txt`에 보관해 즉시 rollback한다.
5. 모델, 규칙, 프롬프트, 안전 문구 버전을 각각 기록한다.

`ContentUpdateInstaller`는 경로 이탈을 차단하고 크기/해시가 하나라도 다르면 전체 설치를 거부한다. 사용자에게 다운로드 용량과 적용 버전을 사전에 표시해야 한다.
