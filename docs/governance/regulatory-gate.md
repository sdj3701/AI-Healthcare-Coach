# 재활 확장 규제 검토 게이트

대상: PBI-005

현재 제품 범위는 질환의 진단·치료·예방·재활이 아닌 일반 피트니스 자세 코칭이다. 아래 조건 중 하나라도 추가되면 기능 개발을 중단하고 출시 국가의 법률·규제 전문가 검토를 받는다.

- 질환명이나 손상명을 추정하거나 사용자에게 진단 결과를 표시한다.
- 치료 효과, 회복 기간, 재활 결과를 예측하거나 보장한다.
- 임상의의 처방을 대체하거나 환자별 운동 강도를 처방한다.
- 의료기관으로 데이터를 전송해 의료 의사결정에 사용한다.
- 센서 결과를 응급 판단의 유일한 근거로 사용한다.

검토 기록에는 국가/지역, 기능 설명, 의도된 사용자, 데이터 흐름, 위험 분석, 법률 검토자, 승인일과 만료일을 포함한다. 승인 문서가 없으면 `Fitness only` 기능 플래그를 유지하고 관련 UI·스토어 문구를 배포하지 않는다.
