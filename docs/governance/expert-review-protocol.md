# 운동 규칙 전문가 검수 프로토콜

대상: PBI-004, PBI-097

1. 검수자는 운동 지도 경력과 이해충돌 여부를 기록한다.
2. 각 규칙의 `rule_id`, 관절 입력, 임계값, 예외 조건, 사용자 문구를 검토한다.
3. 정상·경계·명백한 오류 합성 좌표와 실사용 영상 없는 좌표 세션을 각각 확인한다.
4. 결과는 `승인`, `수정 후 승인`, `Beta 검증 필요`, `사용 금지` 중 하나로 기록한다.
5. 통증·진단·치료·재활을 암시하는 문구는 즉시 사용 금지로 분류한다.
