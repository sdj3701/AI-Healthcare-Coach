# 사용성 테스트 스크립트

대상: PBI-096

참가자에게 기능을 설명하지 않고 다음 과제를 순서대로 요청한다.

1. 앱의 데이터 처리 방식과 의료 앱이 아닌 이유를 설명해 달라고 한다.
2. 카메라 권한을 허용하고 스쿼트 8회를 목표로 설정한다.
3. 카메라 위치가 잘못된 상태에서 스스로 수정하게 한다.
4. 운동 중 텍스트/음성/진동 설정을 원하는 방식으로 바꾼다.
5. 운동을 종료하고 오류 구간 리플레이와 리포트를 찾는다.
6. 공유 미리보기에서 포함되지 않는 정보를 설명한다.
7. 해당 세션 데이터를 삭제한다.

측정값: 과제 성공 여부, 소요 시간, 도움 요청 횟수, 잘못된 클릭, 안전 문구 이해도, 개인정보 신뢰도 1~5, 리포트 이해도 1~5. 진행자는 통증을 유도하거나 운동 수행을 강요하지 않으며 언제든 중단할 수 있음을 먼저 고지한다.
