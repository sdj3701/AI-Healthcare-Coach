# 깊은 스쿼트를 올바른 판정으로 변경하는 계획

## 요구사항

- 기존의 “너무 깊게 내려갔습니다” 판정을 모두 제거한다.
- 기존 과도한 깊이 조건에 해당하더라도 다른 자세 오류가 없다면 올바른
  최저점으로 판정한다.
- 과도한 깊이 TTS, 실패 횟수, 세션 문제 기록이 남지 않게 한다.

## 변경 원칙

1. 순차 최저점 판정은 다음 순서까지만 사용한다.
   - 1차 엉덩이-무릎 높이
   - 무릎 안쪽 정렬
   - 개인 목표 깊이
   - 위 조건을 모두 통과하면 무릎 각도가 기존 과도한 깊이 기준보다
     작더라도 `Passed`
2. 깊은 자세를 별도 Warning 이벤트로 생성하지 않는다.
3. 깊은 자세를 올바른 반복 횟수에서 제외하거나 세션 이슈로 기록하던 경로를
   제거한다.
4. 구형 자세 분석기에서도 `*_knee_bend_deep` 경고를 생성하지 않는다.
5. 이전 세션이나 외부 입력에 남은 깊이 과다 규칙이 재생되더라도
   “너무 깊다”는 문구가 나오지 않도록 규칙 카탈로그와 UI 호환 표시를
   올바른 깊이로 바꾼다.
6. 무릎 각도와 깊이 통계 원본은 진단 목적으로 유지하되 실패 판정에는
   사용하지 않는다.

## 코드 변경 범위

- `RealtimePoseRuleEngine`
  - `squat_depth_excessive` 이벤트 생성 분기 제거
  - 앞선 조건 통과 시 항상 `SquatBottomDecision.Passed`
- `ExercisePhaseState`, `RealtimeFeedbackOrchestrator`,
  `RepQualityAccumulator`
  - 과도한 깊이 실패 상태, 감점, 세션 이슈 처리 제거
- `PoseExerciseFeedbackAnalyzer`, `PoseFeedbackAnalyzer`
  - 최소 무릎 각도 미만의 깊은 자세 경고 제거
- `MobileWorkoutPrototypeView`
  - 이전 과도한 깊이 값이나 규칙 ID가 들어와도 “올바른 깊이”로 표시
- RAG 규칙 카탈로그와 깊이 문서
  - “너무 깊게 내려갔습니다” TTS 제거
  - 이전 규칙은 비활성 호환 항목으로 유지하며 올바른 자세 문구로 변경
- `HealthcareQaSuite`
  - 연속 깊은 프레임도 이벤트 없이 `Passed`가 되는지 검증
  - `squat_depth_excessive`가 rep 실패 후보가 아닌지 검증

## 문서 변경

- 현재 자세 판정 문서의 최저점 흐름에서 과도한 깊이 실패 단계를 제거한다.
- 깊은 자세는 앞선 높이·정렬·개인 깊이 조건을 통과하면 올바른 자세로
  처리된다고 명시한다.
- 이전의 과도한 깊이 안전 기준 설명은 현재 정책에서 비활성임을 기록한다.

## 검증

- [x] Unity C# 컴파일 오류가 없다.
- [x] Healthcare 결정론 QA가 통과한다.
- [x] 기존 과도한 깊이 연속 프레임 입력이 `Passed`로 판정된다.
- [x] `squat_depth_excessive`, `squat_depth_deep`,
      `*_knee_bend_deep` Warning이 생성되지 않는다.
- [x] 올바른 반복 횟수와 “올바른 자세입니다” TTS 경로를 사용할 수 있다.
- [x] “너무 깊게 내려갔습니다”, “깊이를 줄여 주세요” 문구가 런타임
      콘텐츠에 남지 않는다.

## 완료 결과

- Unity 6000.3.18f1에서 스크립트 어셈블리 리로드가 정상 완료되었다.
- Healthcare 결정론 QA가 `AI_HEALTHCARE_QA_PASSED`로 통과했다.
- 과도하게 깊은 자세는 앞선 높이·정렬·개인 깊이 조건을 통과하면
  `Passed`로 처리하며, 과도한 깊이 TTS나 세션 오류를 생성하지 않는다.
