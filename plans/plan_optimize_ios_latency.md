# 📌 작업 계획서: 아이폰 관절 인식 반응속도 최적화

## 1. 개요 및 목표
* 아이폰 실기기 환경에서 카메라 이미지의 CPU-to-GPU 병목 및 연산 부하를 최소화하고, 필터 반응 민감도를 높여 실시간 자세 분석 반응속도를 극대화합니다.

## 2. 주요 작업 단계 (대표 작업 리스트)
- [x] **Step 1: iOS 기기 카메라 요청 해상도 제한 (Cap)**

## 3. 예상 예외 사항 및 제약 조건과 코드 구현이유
* **카메라 해상도 제한 이유**: 모바일 기기의 CPU 픽셀 복사(`GetPixels32`) 및 Swift 브릿지 간의 복사량이 70% 이상 줄어들어 프레임 드랍이 사라지고 반응속도가 비약적으로 개선됩니다. 
  * *장점*: 기기 발열과 배터리 소모를 극적으로 낮추며, 실시간 반응속도(FPS)가 향상됩니다.
  * *단점*: 카메라 프리뷰 이미지가 다소 덜 선명하게 보일 수 있으나, 피트니스 트래킹용 모바일 화면 스펙으로는 충분한 화질을 보장합니다.
* **관절 평활화 필터 알파값 변경 이유**: 프레임 누적 필터 지연을 낮추어 사용자의 움직임 변화를 더 민감하고 기민하게 관절에 투영하도록 변경합니다.
  * *장점*: 빠른 동작(예: 스쿼트 하강/상승 전환) 시 관절 트래킹 지연이 크게 감소합니다.
  * *단점*: 기기 조명 환경이 좋지 않을 때 관절 랜드마크의 미세한 흔들림(노이즈)이 살짝 증가할 수 있습니다.
